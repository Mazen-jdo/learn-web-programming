هي اختصار لـ JavaScript . هي لغه برمجه عالية المستوى تستخدم بشكل اساسي لجعل صفحات الويب تفاعليه وحيوية .

💡 تشبيه بسيط: اذاكانت HTML هي الهيكل الذي يحدد البنيه و CSS هي التنسيق التي تمنح الجمال والتناسق فان JavaScript هي التي تعطي الموقع القدرة على الحركه والتفاعل

1. المتغيرات (Variables)

تُستخدم المتغيرات لتخزين البيانات في ذاكرة البرنامج. في جافاسكريبت الحديثة نستخدم let للمتغيرات القابلة للتغيير و const للقيم الثابتة.

مثال عملي:

let score = 100;
const pi = 3.14;

score = 150; // يمكن تغيير قيمته
// pi = 3.15; -> هذا سيعطي خطأ لأن const لا يمكن إعادة تعيينه

console.log("النتيجة:", score);

2. أنواع البيانات (Data Types)

تتعامل جافاسكريبت مع عدة أنواع من البيانات الأساسية مثل النصوص (String)، الأرقام (Number)، والقيم المنطقية (Boolean).

مثال عملي:

let text = "مرحباً بك"; // String
let count = 10;          // Number
let isReady = true;     // Boolean
let emptyVal = null;    // Null (قيمة فارغة)

console.log(typeof text); // يطبع: string

3. الشروط (Conditional Statements)

تُستخدم لاتخاذ القرارات في الكود بناءً على تحقق شرط معين باستخدام if و else.

مثال عملي:

let age = 18;

if (age >= 18) {
    console.log("يسمح لك بالدخول");
} else {
    console.log("عذراً، هذا المحتوى للبالغين فقط");
}

4. الدوال (Functions)

الدالة عبارة عن كتلة من الكود تُنفذ مهمة محددة عند استدعائها، وتساعد في تجنب تكرار الكود.

مثال عملي:

// دالة تقليدية
function addNumbers(a, b) {
    return a + b;
}

// Arrow Function (دالة السهم الحديثة)
const multiply = (a, b) => a * b;

console.log(addNumbers(5, 3)); // 8
console.log(multiply(4, 2));   // 8

5. المصفوفات (Arrays)

تُستخدم المصفوفة لتخزين قائمة من العناصر تحت اسم متغير واحد.

مثال عملي:

let fruits = ["تفاح", "موز", "برتقال"];

// إضافة عنصر جديد
fruits.push("مانجو");

// طباعة العنصر الأول (الفهرس يبدأ من 0)
console.log(fruits[0]); // تفاح
console.log("عدد الفواكه:", fruits.length);

6. الكائنات (Objects)

تُستخدم الكائنات لتخزين البيانات على شكل أزواج من (المفتاح والقيمة - Key & Value).

مثال عملي:

let car = {
    brand: "Toyota",
    model: "Camry",
    year: 2022,
    start: function() {
        console.log("المحرك يعمل...");
    }
};

console.log(car.brand); // Toyota
car.start(); // المحرك يعمل...

7. الحلقات التكرارية (Loops)

تُستخدم الحلقات التكرارية لتكرار تنفيذ كود معين لعدد محدد من المرات.

مثال عملي:

// حلقة for البسيطة
for (let i = 1; i <= 3; i++) {
    console.log("التكرار رقم: " + i);
}

// التكرار على مصفوفة
let colors = ["أحمر", "أخضر", "أزرق"];
colors.forEach(function(color) {
    console.log("اللون:", color);
});

8. التحكم بعناصر الصفحة (DOM Manipulation)

يتيح لك الـ DOM الوصول إلى عناصر الـ HTML وتعديل نصوصها أو أنماطها برمجياً.

مثال عملي:

// تحديد عنصر وتغيير نصه
let titleElement = document.getElementById("main-title");
titleElement.innerText = "العنوان الجديد!";

// تغيير لون العنصر
titleElement.style.color = "blue";

9. الأحداث (Events)

تتيح الأحداث للكود الاستجابة لتفاعلات المستخدم مثل الضغط على زر أو الكتابة في الحقول.

مثال عملي:

let myButton = document.querySelector("button");

myButton.addEventListener("click", function() {
    alert("تم الضغط على الزر بنجاح!");
});

10. التخزين المحلي (LocalStorage)

يسمح لك بتخزين بيانات بسيطة داخل متصفح المستخدم لتبقى محفوظة حتى بعد إغلاق الصفحة.

مثال عملي:

// حفظ قيمة في المتصفح
localStorage.setItem("theme", "dark");

// استرجاع القيمة
let currentTheme = localStorage.getItem("theme");
console.log("المظهر الحالي:", currentTheme);

11. البرمجة غير المتزامنة (Async / Await & Fetch)

تُستخدم لجلب البيانات من خوادم خارجية (APIs) دون إيقاف تشغيل الصفحة أثناء الانتظار.

مثال عملي:

async function fetchData() {
    try {
        let response = await fetch("https://api.example.com/data");
        let data = await response.json();
        console.log(data);
    } catch (error) {
        console.log("حدث خطأ أثناء جلب البيانات:", error);
    }
}

12. النصوص المتقدمة (Template Literals)

طريقة حديثة لدمج المتغيرات داخل النصوص بسهولة باستخدام العلامة المائلة (Backticks `) دون الحاجة لعلامات +.

مثال عملي:

let name = "علي";
let age = 22;

// استخدام Backticks والمرمز ${}
let message = `مرحباً، اسمي ${name} وعمري ${age} سنة.`;

console.log(message);

13. كائن الرياضيات (Math Object)

يوفر كائن Math الجاهز في اللغة مجموعة من الدوال للعمليات الرياضية مثل التقريب والأرقام العشوائية.

مثال عملي:

// تقريب الأرقام
console.log(Math.round(4.7)); // 5

// توليد رقم عشوائي بين 0 و 10
let randomNum = Math.floor(Math.random() * 10) + 1;
console.log("رقم عشوائي:", randomNum);

14. التعامل مع التواريخ (Date Object)

يُستخدم الكائن Date للتعامل مع الوقت والتاريخ الحالي واستخراج السنة، الشهر، أو اليوم.

مثال عملي:

let now = new Date();

console.log("التاريخ الكامل:", now);
console.log("السنة الحالية:", now.getFullYear());
console.log("الشهر (0-11):", now.getMonth());

15. معالجة المصفوفات (Map & Filter)

دوال حديثة تُستخدم لتصفية العناصر أو تعديل بيانات المصفوفة وإنشاء مصفوفة جديدة بدون التعديل على الأصلية.

مثال عملي:

let numbers = [1, 2, 3, 4, 5, 6];

// filter: تصفية الأرقام الزوجية فقط
let evenNumbers = numbers.filter(n => n % 2 === 0); // [2, 4, 6]

// map: مضاعفة كل رقم في المصفوفة
let doubled = numbers.map(n => n * 2); // [2, 4, 6, 8, 10, 12]

16. معالجة الأخطاء (Try / Catch)

تُستخدم لمنع توقف البرنامج تماماً عند حدوث خطأ غير متوقع أثناء تشغيل الكود.

مثال عملي:

try {
    // محاولة تنفيذ كود قد يحتوي على خطأ
    let result = undefinedFunction(); 
} catch (error) {
    // الكود الذي يعمل في حال حدوث خطأ
    console.log("حدث خطأ في البرنامج ولكن تم التعامل معه!");
    console.log("رسالة الخطأ:", error.message);
}
