ماهي css وماهي وظيفتها؟

هي اختصار لـ Cascading Style Sheet . هي لغه التنسيق الاساسية لصفحات الويب المكتوبة بلغه HTML.

💡 تشبيه بسيط: اذا كانت HTML هي الهيكل الذي يحددمكونات الصفحه (كنص ,صورة ,زر )فان css هي المظهر الخارجي التي تمنح الصفحه شكلها النهائي الجذاب

المرحلة الأولى: بنية الكود والمحددات (Selectors)

1. كيف يكتب كود الـ CSS؟ (Syntax)

لكي نتحكم في مظهر أي عنصر، نحتاج إلى كتابة الكود بصيغة يفهمها المتصفح. تتكون هذه الصيغة من المحدد (Selector) الذي نختاره، ثم نفتح أقواس مجعدة ونضع داخلها الخاصية (Property) والقيمة (Value).

مثال لتلوين العناوين باللون الأزرق وتكبيرها:
h1 {
    color: #2980b9;
    font-size: 24px;
}

2. أنواع المحددات الأساسية

المحددات هي طريقة مناداة العناصر. يمكنك استهداف العنصر باسمه المباشر، أو عبر الكلاس .class عند رغبتك في تكرار التنسيق، أو عبر الآي دي #id لعنصر واحد فريد في الصفحة.

طرق الاستهداف المختلفة في الـ CSS:
/* استهداف باسم الوسم */
p { color: grey; }

/* استهداف بواسطة الكلاس (يستخدم لنفس المجموعات) */
.card { background-color: white; }

/* استهداف بواسطة الآي دي (فريد وخاص بعنصر واحد) */
#css-page { background-color: #f8fafc; }

المرحلة الثانية: فهم نموذج الصندوق (Box Model)

3. ما هو الـ Box Model؟

في الـ CSS، يعتبر المتصفح كل عنصر في صفحتك عبارة عن مستطيل أو "صندوق" مغلق. هذا الصندوق يتكون من أربع طبقات أساسية تتحكم في حجمه والمساحات المحيطة به.

💡 تشبيه تقريبي: تخيل أنك تشتري حذاءً جديداً أرسل إليك في صندوق شحن؛ الحذاء نفسه هو (Content)، وورق التغليف المنفوخ لحماية الحذاء بالداخل هو (Padding)، وصندوق الكرتون المقوى نفسه هو (Border)، والمساحة الفارغة التي تتركها بين هذا الصندوق والصناديق الأخرى في الغرفة هي (Margin).
تطبيق نموذج الصندوق على البطاقات التعليمية:
.card {
    padding: 30px;         /* مسافة مريحة للنصوص بالداخل */
    border-right: 6px;     /* سمك الإطار الأيمن للبطاقة */
    margin-bottom: 25px;   /* إبعاد البطاقة عن البطاقة التي أسفلها */
}

المرحلة الثالثة: التخطيط المرن (Flexbox)

4. نظام التوزيع والترتيب الذكي

يعتبر نظام Flexbox من أقوى الأدوات لتوزيع العناصر داخل الصفحة بشكل أفقي أو رأسي تلقائياً. بمجرد إعطاء العنصر الأب خاصية display: flex;، تتحول جميع العناصر الأبناء إلى عناصر مرنة يمكنك التحكم بمحاذاتها وفراغاتها بسطر واحد.

تنسيق شريط الأزرار (Navbar) ليكون متراصاً ومتوسطاً:
.navbar {
    display: flex;             /* تفعيل النظام المرن */
    justify-content: center;   /* توسيط الأزرار أفقياً في المنتصف */
    gap: 15px;                 /* ترك مسافة ذكية وثابتة بين كل زر والآخر */
}

المرحلة الرابعة: الألوان والنصوص (Typography & Colors)

5. تنسيق الخطوط واختيار الألوان

الخطوط والألوان هي روح التصميم. في الـ CSS نتعلم كيف نغير حجم الخط، ونوعه، وكيفية كتابة الألوان بثلاث طرق مختلفة: الأسماء المباشرة، أو نظام الـ HEX، أو نظام RGB الذي يسمح لنا بالتحكم في شفافية اللون.

تغيير ستايل النصوص وتطبيق الشفافية:
.card p {
    font-size: 1rem;            /* حجم خط مرن ومريح للعين */
    line-height: 1.6;           /* ترك مسافة بين الأسطر لسهولة القراءة */
    color: rgba(0, 0, 0, 0.8);  /* لون أسود شفاف بنسبة 80% مريح للنظر */
}

المرحلة الخامسة: التصميم المتجاوب (Responsive Design)

6. شاشات الكمبيوتر والموبايل (Media Queries)

الموقع الناجح هو الذي يغير شكله تلقائياً ليتناسب مع شاشة الموبايل الضيقة وشاشة الكمبيوتر الواسعة. نستخدم لهذا الغرض أداة سحرية تسمى @media تخبر المتصفح: "إذا صغرت الشاشة عن حد معين، قم بتغيير التنسيقات فوراً".

تغيير اتجاه العناصر في الموبايل ليصبح عمودياً بدلاً من أفقي:
@media (max-width: 768px) {
    .navbar {
        flex-direction: column; /* ترتيب أزرار القائمة تحت بعضها في الهواتف */
        gap: 10px;
    }
}
